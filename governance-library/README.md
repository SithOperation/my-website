# Cybersecurity Governance Source Library

This package follows the supplied source list. It does not substitute generated policies for authoritative publications.

Each source has its own folder containing official links, source metadata, a companion source summary, and machine-readable Codex instructions.

## Status labels

- `OFFICIAL_PDF_SOURCE`: the publisher provides a direct official PDF link.
- `OFFICIAL_WEB_SOURCE`: the authority is maintained on an official webpage or online catalog.
- `LICENSED_LINK_ONLY`: the underlying publication is licensed or distribution-restricted; only an original companion summary and official publisher link are included.

## Codex rule

Codex must create new content only in each folder's `Companion/` directory. It must preserve official links and metadata, cite exact source locators, distinguish binding requirements from voluntary guidance, and mark unsupported claims `UNVERIFIED`.

## Binary-file note

No document in this package is falsely represented as an official PDF binary. The package provides direct publisher PDF links where available.

NIST SP 800-18 Rev. 2, published June 30, 2026, is the current system-planning
record in this package. Withdrawn Rev. 1 is intentionally excluded. Licensed
ISO and similar packages are not missing accidentally: their official
publication bodies are link-only, with local original companion records rather
than copied standards text.
