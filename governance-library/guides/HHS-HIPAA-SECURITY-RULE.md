# HIPAA Security Rule and NIST SP 800-66 Rev. 2 — Source Guide

> Joseph Technologies independent research guide. This is not legal advice. Confirm applicability and interpretations with qualified counsel and the current HHS/OCR and eCFR sources.

## Authority and applicability

The HIPAA Security Rule establishes safeguards for electronic protected health information handled by covered entities and business associates. Unlike voluntary NIST guidance, applicable HIPAA regulations are binding. NIST SP 800-66 Rev. 2 is implementation guidance and does not replace the regulation.

## Primary regulatory locations

- 45 CFR §164.308: administrative safeguards.
- 45 CFR §164.310: physical safeguards.
- 45 CFR §164.312: technical safeguards.
- 45 CFR §164.314: organizational requirements.
- 45 CFR §164.316: policies, procedures, and documentation.
- 45 CFR §§164.400–414: breach-notification requirements.

## Governance documentation commonly needed

- designated security official and assigned responsibilities;
- risk analysis and risk-management records;
- sanction and workforce-security processes;
- information-system activity review;
- contingency planning;
- incident procedures;
- business-associate governance;
- policy, procedure, approval, retention, and review records.

## Required distinctions

- Separate the currently effective Security Rule from proposed modifications.
- Separate Security Rule, Privacy Rule, and Breach Notification Rule obligations.
- Separate binding regulatory text from HHS and NIST implementation guidance.
- Do not claim that using a template establishes HIPAA compliance.

## Related implementation source

NIST SP 800-66 Rev. 2 provides a cybersecurity resource guide for implementing the HIPAA Security Rule. Use its implementation considerations and mappings as guidance while treating the current eCFR text as the controlling legal source.
